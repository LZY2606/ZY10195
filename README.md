# 地下环闭合仪

三维导线网（洞穴/地下测量）闭合差检核与加权最小二乘平差的本地服务。
技术栈：TypeScript + Node.js（内置 `node:http` / `node:sqlite`，零运行时依赖）+ SQLite + Canvas。

## 运行

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm test -- --run
corepack pnpm dev --host 127.0.0.1 --port 5535
# 打开 http://127.0.0.1:5535 ，页面标题为「地下环闭合仪」
```

数据库文件默认在 `data/cave.db`（可用环境变量 `CAVE_DB_PATH` 覆盖），首次启动自动导入固定算例。

## 数据口径

- **测站**：身份由 `id` 决定，`name` 仅用于展示。**重名测站绝不按名称合并**
  （算例中 `P1` 与 `X1` 同名 "A1"，分属不同分量）。
- **观测**：测站间斜距(m)、方位角(度)、倾角(度，水平为 0)、仪器高/觇标高(m)。
  原始记录字段（`from/to/slope/azimuth/incl/hi/ht`）只由算例导入写入，**平差永不改写原观测**。
- **往返观测**：同一测站对上的两条独立记录（同 `group`，如 RT1 的 `o2`/`o3`），
  是同一连接上的两条证据；拓扑成环时往返边不构成额外环。
- **翻转候选**：疑似写反（from/to 记录颠倒）的边可标记为翻转候选。
  语义 = 交换测站标签、数值不变（物理测回不变，仅记录方向写反）；
  只影响平差解释，不覆盖任何记录，往返两条证据各自独立翻转。
- **权重**：每条观测的用户权重倍数（默认 1），乘在由仪器标称精度
  （测距 5mm+2ppm、测角 5″）传播得到的协方差逆阵上。
- **方位角跨零度**：所有方位残差/不符值按最短环绕归算到 (-180°, 180°]，
  不会产生接近整圈的伪误差。
- **平差模型**：斜距/方位/倾角 → 三维基线向量观测（协方差由误差传播得来）的线性 WLS；
  仅方位边贡献 1 个方向方程（无尺度）。锁定控制点提供平移基准；
  法方程 N=AᵀWA 直接求逆解算，同时给出协因数阵 Q、误差椭球(1σ)与 σZ。
- **秩亏报告**：按连通分量计算秩与不可识别自由度（秩亏维数），并标注来源
  （平移基准缺失 / 无距离导致尺度不可识别 / 其余如高程基准）。秩亏分量不参与平差，坐标记为不可解。
- **最小独立闭合路**：连接级（往返边合并为一条连接）图上用 Horton 最小环基算法求
  最小独立闭合路；闭合差为向量闭合差 |f|、相对精度 1/N，以及往返方位不符值。

## 固定算例（fixture）

- 主网：控制点 `K01`（已知坐标、默认锁定）+ 测站 `P1(A1)/P2(B2)/P3(C3)`，
  构成 1 个独立闭合环 K01→P1→P2→P3→K01；`P1↔P2` 为往返观测（RT1）；
  `o5` 记录为 K01→P3，但物理测回是 P3→K01（**疑似写反**，未翻转时环闭合差约 153m，
  翻转后降至毫米级）。
- 孤立子图：`X1(A1，重名)/X2(D4)/X3(E5)`，仅方位观测、无距离 → 秩亏 7 维
  （平移基准 3 + 尺度 1 + 高程等 3），报告中输出不可识别自由度。

## 页面操作

- 站点图（Canvas）：测站、观测边、选中闭合路高亮、误差椭球（夸大 400×）、残差向量（夸大 400×）。
- 面板：网结构摘要、闭合路列表（点击高亮）、法方程诊断（秩/秩亏/自由度/σ₀/条件数估计）、
  测站锁定开关、观测权重编辑与翻转候选、平差后坐标、运行记录。
- 「运行平差」：按当前锁定/权重/翻转候选状态解算并保存一条运行记录。
- 「清空并重新导入算例」：清空测站与观测表并重新导入 fixture（运行记录保留，便于复核）。

## 运行记录与复核（重放）

- 每次平差保存到 SQLite `runs` 表，包含网结构摘要、法方程诊断、平差后坐标与每条观测的残差。
- 导出：`GET /api/runs/<id>/export`（页面「运行记录」面板有导出链接），得到完整 JSON。
- 复核：清空数据库（页面按钮或 `POST /api/reset`）后自动重新导入固定算例，
  重放相同操作（锁定/权重/翻转）再运行平差，结果可与导出的运行记录比对。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 测站、观测、网结构摘要、分量诊断、闭合路、运行记录列表 |
| POST | `/api/adjust` | 运行平差并保存运行记录 |
| POST | `/api/observation` | `{id, weight?}` 改权重；`{id, flipped?}` 设/取消翻转候选 |
| POST | `/api/station` | `{id, locked}` 锁定/解锁控制点 |
| POST | `/api/reset` | 清空并重新导入固定算例 |
| GET | `/api/runs` · `/api/runs/<id>` · `/api/runs/<id>/export` | 运行记录查询/导出 |
